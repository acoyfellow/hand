Don't let a model guess pixels. List what can be clicked, and let a small model choose.

do is a computer-use library. A device lists the controls on screen in code. Clef, Cloudflare's small decision model, picks one with a probability. The device acts, and Clef checks whether it worked. A larger model is called only when a task needs text that is not in it word for word.

The only real device today is macOS, through the accessibility API. The benchmark drives a test app in a browser.

A real 38 s recording. Clef + Clairic types "jordan at cloudflare dot com" as written and fails. The relay arm sees the task needs new text, a writer fills the field once, and Clef still makes every click.

How it works

screen ──► device lists controls ──► Clef: "which one?" + probability
  ▲                                         │
  └── Clef: "did it work?" ◄── device acts ◄┘
DeviceSees and touches a screen: lists controls (role, name, box), presses, types, sets values. do/devices/macos drives real Mac apps through the accessibility API.
ClefPicks from a list, with a probability. It never writes text.
ClairicCopies values out of the task. It never writes text that is not already there.
WriterWrites field values only when Clef says the task needs new text. Default: glm-5.3-flash, with kimi-k2.6 filling any field glm leaves empty.
HandWhat you call: act, type, select, look. Refuses when Clef is unsure, blocks destructive controls unless confirmed, returns a one-line receipt. The caller never receives an image.

Use it

Install from GitHub.

bun add github:acoyfellow/do
swiftc -O node_modules/do/native/ax.swift -o ax   # macOS helper, once
import { gatewayTransport } from 'do/clef';
import { readConfig, readToken } from 'do/credentials';
import { macosDevice } from 'do/devices/macos';
import { Hand } from 'do/hand';

const transport = gatewayTransport({ ...readConfig(), token: readToken() });
const device = macosDevice({ helper: './ax', app: 'Google Chrome' });
const hand = new Hand(transport, device, { model: 'clef', method: 'ax_text', tau: 0.3, riskTau: 0.5, injectionTau: 0.5, verify: true });

await hand.act('switch to the termlab tab');
→ Clicked radio "termlab — web terminal benchmark" (p=0.86).
await hand.type('coey.dev', 'the address bar');
→ Typed into textbox "Address and search bar" (p=0.97).
await hand.look('Is coey.dev open?');
→ p(yes)=0.99

Credentials: a Cloudflare AI Gateway account, gateway name and scoped token, read the same way as odds (see its quick start). On a Mac, the device presses controls through accessibility so the mouse does not move, and sends keystrokes only to the target app, refusing if it is not frontmost.

Bench

Every change to src/ has to pass a fixed bench: 30 tasks in a local test app, success read from the app's own state, and a gate that fails on stale or worse results.

bun run check   # typecheck, lint, tests
bun run gate   # fails if results are stale or worse than baseline
bun run bench:mock   # offline, reproduces the committed reference exactly
bun run bench   # real models, writes bench/runs/<id>/

What this does not show

  • The test app is easy for code to read. Every control has a label. Canvas UIs, unlabelled icons and misleading labels are not tested.
  • The macOS device is new. It has run on Chrome, Finder, Notes and cmux by hand; there is no desktop task set in the bench yet.
  • One planner, one app, 30 tasks. Treat differences under about 3 tasks as noise.
  • The Opus numbers are from bench-2, before the writer pair existed, and have not been rerun.
  • No MCP server or CLI yet. No Windows or Linux devices.
